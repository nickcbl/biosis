Exercícios de Lógica de Programação para Biotecnologia

Resolvidos apenas com if/else, for e while

Regras destes exercícios

O objetivo é praticar lógica, sem usar funções prontas de Python. Por isso, em todas as soluções:

  • Não usar: sum(), max(), min(), sorted(), reversed(), count(), any(), all(), list comprehensions, slicing reverso ([::-1]).
  • São permitidas: if/elif/else, for com range(), while, listas apenas como armazenamento (append, acesso por índice), e len() apenas para controlar o tamanho de um laço (nunca para “resolver” o problema).
  • Nos exemplos abaixo, os dados de entrada estão definidos diretamente nas variáveis (para o documento rodar sozinho). Em aula, vocês podem trocar por input().

Nível 1 — Condicionais (if/else)

1. Classificação de pH

Dado um valor de pH, classifique a amostra como ácida (pH < 7), neutra (pH = 7) ou básica (pH > 7).

2. Purina ou pirimidina

Dada uma base nitrogenada (A, T, C ou G), diga se ela é uma purina (A, G) ou uma pirimidina (T, C).

3. Faixa segura de armazenamento

Dada uma temperatura de um freezer de laboratório, diga se está dentro da faixa segura para armazenar amostras de DNA (-25°C a -15°C).

4. Fase do ciclo celular

Dado um código numérico (1 a 4), informe a fase correspondente do ciclo celular: 1 = G1, 2 = S, 3 = G2, 4 = M.

Nível 2 — Repetição com for

5. Contagem de bases nitrogenadas

Dada uma sequência de DNA, conte quantas vezes aparecem A, T, C e G.

6. Conteúdo GC

Calcule a porcentagem de bases G e C em uma sequência de DNA.

7. Fita complementar

Gere a fita complementar de uma sequência de DNA (A↔︎T, C↔︎G).

8. Diluição seriada

Simule N diluições seriadas de uma amostra: a cada passo, a concentração é dividida pelo fator de diluição.

9. Crescimento populacional bacteriano

Uma cultura bacteriana duplica a cada geração. Dado o número inicial de células e o número de gerações, calcule a população final, mostrando geração a geração.

Nível 3 — Laços aninhados

10. Todos os códons possíveis (RNA)

Gere e imprima todos os 64 códons possíveis de RNA (combinações de 3 bases entre A, U, C, G), usando três laços for aninhados.

11. Contagem de dinucleotídeos

Conte quantas vezes cada par de bases consecutivas (dinucleotídeo, ex: “AT”, “CG”) aparece em uma sequência, usando dois laços for para comparar cada par possível.

Nível 3.5 — Laço aninhado + acumulador (o salto de dificuldade)

Aqui os dois laços trabalham juntos: o laço externo passa por vários “itens” (sequências, poços de uma placa) e o laço interno calcula algo sobre cada item, que é acumulado ou comparado no laço externo. É normalmente aqui que a turma trava — vale desenhar no quadro o que cada laço está fazendo separadamente antes de juntá-los.

12. Sequência com maior conteúdo GC

Dada uma lista de sequências de DNA, descubra qual delas tem o maior conteúdo GC, sem usar max(). Para cada sequência (laço externo), calcule o GC content (laço interno) e compare com o melhor resultado encontrado até agora.

13. Soma de absorbância por linha de uma microplaca

Uma microplaca de 96 poços foi organizada em 8 linhas de 12 colunas (representada como uma lista de listas). Para cada linha, some as absorbâncias dos poços (laço interno) e mostre o total (laço externo).

14. Total de um códon específico em várias sequências de RNA

Dada uma lista de sequências de RNA, conte quantas vezes o códon de início AUG aparece somando as ocorrências em todas as sequências.

Nível 4 — Acumuladores, contadores e listas

15. Maior e menor absorbância de uma leitura

Dada uma lista de leituras de absorbância (espectrofotômetro), encontre o maior e o menor valor sem usar max()/min().

16. Controle de qualidade de amostras

Dada uma lista de concentrações de amostras de DNA, conte quantas estão dentro do intervalo aceitável (entre 20 e 200 ng/uL) e calcule a porcentagem de aprovação.

17. Inverter uma sequência de DNA

Inverta uma sequência de DNA sem usar slicing reverso ([::-1]).

18. Validação de sequência

Verifique se uma sequência contém apenas bases válidas (A, T, C, G). Use uma variável “flag” booleana.

Nível 5 — while (repetição de tamanho desconhecido)

19. Diluições até atingir um limite

Simule diluições seriadas sucessivas até que a concentração fique abaixo de um limite mínimo de detecção. Como não se sabe de antemão quantas diluições serão necessárias, use while.

20. Busca de um motivo (motif) em uma sequência

Procure a primeira posição em que um pequeno trecho (motif) aparece dentro de uma sequência de DNA. Pare assim que encontrar.

21. Contagem de códons até encontrar um stop códon

Percorra uma sequência de RNA de 3 em 3 bases (códons) e pare ao encontrar o primeiro códon de parada (UAA, UAG ou UGA), contando quantos códons foram lidos até ali (incluindo o de parada).
