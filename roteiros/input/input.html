AULA 1 – Unix Básico

  • sequencias.fasta: Arquivo FASTA com 5 sequências de exemplo (E. coli, B. subtilis, P. aeruginosa).

AULA 3 – Montagem de Genomas

  • adapters.fa: arquivo FASTA com sequências de adaptadores para remoção de contaminação em dados de sequenciamento.
  • SRR022820_1.fastq.xz: arquivo FASTQ com reads 1 do par (forward);
  • SRR022820_2.fastq.xz: arquivo FASTQ com reads 2 do par (reverse);
  • SRR2584857_1.fastq.xz: arquivo FASTQ com reads 1 do par (forward);
  • SRR2584857_2.fastq.xz: arquivo FASTQ com reads 2 do par (reverse);

AULA 5 – Anotação Funcional

  • virulence_genes.txt: Banco de dados de genes de virulência (VFDB) para anotação funcional.

AULA 6 – RNA-SEQ

  • SRR390728_1.fastq.xz: Arquivos FASTQ para o pipeline de RNA-seq (paired-end). (Forward reads).

  • SRR390728_2.fastq.xz: Arquivos FASTQ para o pipeline de RNA-seq (paired-end). (Reverse reads).

AULA 7 – Quantificação de RNA-Seq

  • Homo_sapiens.GRCh38.104.gtf.xz: Arquivo de anotação do genoma humano (Ensembl release 104).

Comando para descompactar:

unxz Homo_sapiens.GRCh38.104.gtf.xz

AULA 8 – Redes de Coexpressão (WGCNA)

  • expressao_normalizada.txt: Matriz de expressão gênica normalizada (genes × amostras) para análise de coexpressão.

AULA 11 – CellDesigner E COPASI

parametros_repressilator.txt

  • parametros_repressilator.txt ⬇️: Parâmetros cinéticos do repressilador para simulação no COPASI.

Guia Rápido de Download

Comando para baixar todos os arquivos de uma vez:

#!/bin/bash
# download_all.sh

# Criar diretório
mkdir -p dados/{fasta,fastq,anotacoes,expressao}
mkdir -p aulas/aula11

# Download dos arquivos
echo "Baixando sequencias.fasta..."
wget -O dados/fasta/sequencias.fasta [URL_BASE]/sequencias.fasta

echo "Baixando adapters.fa..."
wget -O dados/anotacoes/adapters.fa [URL_BASE]/adapters.fa

echo "Baixando virulence_genes.txt..."
wget -O dados/anotacoes/virulence_genes.txt [URL_BASE]/virulence_genes.txt

echo "Baixando SRR390728_1.fastq.gz..."
wget -O dados/fastq/SRR390728_1.fastq.gz [URL_BASE]/SRR390728_1.fastq.gz

echo "Baixando SRR390728_2.fastq.gz..."
wget -O dados/fastq/SRR390728_2.fastq.gz [URL_BASE]/SRR390728_2.fastq.gz

echo "Baixando Homo_sapiens.GRCh38.104.gtf.xz..."
wget -O dados/anotacoes/Homo_sapiens.GRCh38.104.gtf.xz [URL_BASE]/Homo_sapiens.GRCh38.104.gtf.xz

echo "Baixando expressao_normalizada.txt..."
wget -O dados/expressao/expressao_normalizada.txt [URL_BASE]/expressao_normalizada.txt

echo "Baixando parametros_repressilator.txt..."
wget -O aulas/aula11/parametros_repressilator.txt [URL_BASE]/parametros_repressilator.txt

echo "✅ Download concluído!"

Instruções de Descompactação

Arquivos .gz (FASTQ)

# Os arquivos .gz NÃO precisam ser descompactados para uso
# As ferramentas (HISAT2, Trimmomatic) trabalham diretamente com .gz

Arquivo .xz (GTF)

# Descompactar o arquivo GTF
unxz Homo_sapiens.GRCh38.104.gtf.xz
# Resultado: Homo_sapiens.GRCh38.104.gtf
