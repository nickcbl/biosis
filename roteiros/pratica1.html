1 Introdução

A linha de comando (terminal/console) é uma ferramenta essencial na bioinformática. O terminal permite:

  • Automatização: Processar muitos arquivos com um único comando.
  • Reprodutibilidade: Documentar cada passo da análise.
  • Acesso a servidores: Conectar-se a clusters de alto desempenho (HPC).
  • Controle fino: Executar ferramentas especializadas.

3 Objetivos

Comandos Básicos: - Navegar no sistema de arquivos usando caminhos absolutos e relativos - Manipular arquivos e diretórios (criar, copiar, mover, remover) - Visualizar e explorar arquivos texto de diferentes tamanhos - Utilizar wildcards (*, ?) e expansão de comandos

Filtros e Processamento: - Buscar padrões em arquivos usando expressões regulares - Contar sequências, caracteres e linhas - Construir pipelines utilizando pipes (|) e redirecionamentos

Bioinformática: - Extrair cabeçalhos de arquivos FASTA - Filtrar sequências por critérios específicos - Contar e analisar sequências biológicas - Compactar e descompactar arquivos de dados

5 Parte 1 – Navegação no Sistema de Arquivos

5.1 Comandos Básicos


# Comando que traz o manual dos comandos
man


# Verificar diretório atual
pwd


# Listar arquivos
ls
ls -l      # detalhado
ls -lh     # detalhado com tamanhos legíveis
ls -a      # inclui arquivos ocultos (.arquivo)
ls -la     # combinação: todos + detalhado


# Criar diretório
mkdir pratica1
mkdir -p pratica1/dados/raw    # cria diretórios aninhados


# Navegar
cd pratica1
cd ..       # voltar um nível
cd ../..    # voltar dois níveis
cd ~        # ir para home
cd -        # voltar para diretório anterior


# Caminhos
ls /home/usuario/pratica1    # caminho absoluto
ls ./pratica1                # caminho relativo (.) = atual
ls ../Downloads              # caminho relativo (..) = pai


# Wildcards
touch arquivo1.txt arquivo2.txt arquivo3.log
ls *.txt                     # lista todos .txt
ls arquivo?                  # ? substitui um caractere
ls arquivo[1-3]*             # [1-3] substitui por 1, 2 ou 3


# Permissões
ls -l
chmod +x script.sh           # torna executável
chmod 755 script.sh          # permissões numéricas

6 Parte 2 – Manipulação de Arquivos e Diretórios

6.1 Comandos Básicos


# Copiar arquivos
cp sequencias.fasta copia.fasta
cp sequencias.fasta pratica1/dados/   # copiar para diretório
cp -r pratica1/ pratica1_backup/      # copiar diretório recursivamente


# Mover/Renomear
mv copia.fasta teste.fasta
mv teste.fasta pratica1/dados/        # mover para diretório
mv pratica1/dados/teste.fasta .       # mover para atual (.)
mv antigo_novo.txt novo_antigo.txt    # renomear


# Remover
rm teste.fasta
rm -i teste.fasta                     # confirmar antes de remover
rm -r pratica1_backup/                # remover diretório recursivamente
rm -rf pratica1_backup/               # FORÇAR remoção (cuidado!)


# Criar arquivos vazios
touch novo_arquivo.txt
touch -t 202401011200 data.txt        # criar com data específica


# Ver tipo de arquivo
file sequencias.fasta
file script.sh

# Visualizar completo

tail sequencias.fasta          # últimas 10 linhas

# Dentro do less:

#   /palavra    - buscar (N = próximo, n = anterior)

#   Ctrl+B      - voltar página

#   q           - sair

# Visualizar linhas específicas
sed -n '10,20p' sequencias.fasta   # linhas 10-20
sed -n '/^>/p' sequencias.fasta    # linhas que começam com >


# Contar linhas/palavras/caracteres
wc -l sequencias.fasta             # número de linhas
wc -c sequencias.fasta             # número de caracteres
wc -w sequencias.fasta             # número de palavras

8 Parte 4 – Busca em Arquivos (grep e expressões regulares)

8.1 Comandos Básicos


# Busca simples
grep ">" sequencias.fasta          # encontrar cabeçalhos
grep "Escherichia" sequencias.fasta


# Busca com contexto
grep -A 3 ">" sequencias.fasta    # 3 linhas após
grep -B 2 ">" sequencias.fasta    # 2 linhas antes
grep -C 1 ">" sequencias.fasta    # 1 linha antes e depois


# Opções úteis
grep -c ">" sequencias.fasta      # contar ocorrências
grep -v ">" sequencias.fasta      # linhas que NÃO contêm
grep -i "atg" sequencias.fasta    # case insensitive
grep -n ">" sequencias.fasta      # mostrar números de linha
grep -l "Escherichia" *.fasta     # listar arquivos com padrão
grep -r "gene:lacZ" .             # buscar recursivamente


# Expressões regulares básicas
grep "^>" sequencias.fasta         # linhas que começam com >
grep "A$" sequencias.fasta         # linhas que terminam com A
grep "TATA[AT]" sequencias.fasta   # TATA seguido de A ou T
grep "AG{2,4}" sequencias.fasta    # A seguido de 2-4 G's
grep -E "GAT|CAT" sequencias.fasta # GAT ou CAT (ERE)


# Extrair informações
grep "^>" sequencias.fasta | cut -d'|' -f2   # extrair espécie
grep "^>" sequencias.fasta | cut -d'|' -f3   # extrair gene

9 Parte 5 – Pipes (|)

9.1 Conceitos Fundamentais

No Unix, todo comando tem três fluxos de dados:

  • stdin (0): entrada padrão (teclado)
  • stdout (1): saída padrão (tela)
  • stderr (2): saída de erro (tela)

O pipe (|) conecta o stdout de um comando ao stdin de outro:

[comando1] → stdout → | → stdin → [comando2] → stdout → tela

9.2 Exemplos Práticos


# Pipeline básico
grep ">" sequencias.fasta | wc -l

# 1. grep encontra cabeçalhos

# 2. wc conta as linhas


# Pipeline com múltiplos comandos
grep -v "^>" sequencias.fasta | tr -d '\n' | wc -c

# 1. remove cabeçalhos

# 2. remove quebras de linha

# 3. conta caracteres (nucleotídeos totais)


# Pipeline com tee (salvar e continuar)
grep ">" sequencias.fasta | tee cabecalhos.txt | wc -l


# Pipeline com sort e unique
grep "^>" sequencias.fasta | cut -d'|' -f2 | sort | uniq -c


# Pipeline complexo
cat sequencias.fasta | \
  grep -v "^>" | \
  tr -d '\n' | \
  grep -o "TATAAT" | \
  wc -l

# Conta ocorrências de TATAAT em sequências (excluindo cabeçalhos)

10 Parte 6 – Redirecionamento

10.1 Comandos de Redirecionamento


# Saída para arquivo (sobrescreve)
echo "Contagem de sequências:" > relatorio.txt
grep -c ">" sequencias.fasta >> relatorio.txt


# Anexar ao arquivo (>>)
echo "Comprimento total:" >> relatorio.txt
grep -v "^>" sequencias.fasta | tr -d '\n' | wc -c >> relatorio.txt


# Redirecionar erros
comando_inexistente 2> erros.log


# Redirecionar stdout e stderr
grep ">" sequencias.fasta > saida.txt 2> erros.txt
grep ">" sequencias.fasta &> saida_erros.txt


# Redirecionar entrada de arquivo
sort < sequencias.fasta   # entrada do arquivo para sort


# Here document
cat > novo_arquivo.txt << EOF
Linha 1
Linha 2
EOF

10.2 Resumo dos Redirecionamentos

Símbolo Descrição
> Redireciona stdout para arquivo (sobrescreve)
>> Redireciona stdout para arquivo (anexa)
2> Redireciona stderr para arquivo
&> Redireciona stdout e stderr
< Redireciona stdin de arquivo
<< Here document

11 Parte 7 – Xargs

11.1 Conceito e Uso

O xargs converte entrada padrão (stdin) em argumentos para um comando. É útil quando comandos não aceitam entrada via pipe diretamente.

11.2 Exemplos Práticos


# Xargs básico
echo "seq1 seq2 seq3" | xargs mkdir   # cria 3 diretórios


# Xargs com -n (número de argumentos por vez)
echo "seq1 seq2 seq3 seq4 seq5" | xargs -n 2 echo "Processando:"


# Xargs com -I (substituição)
ls *.txt | xargs -I {} mv {} backup/{}


# Xargs com -P (paralelismo)
grep "^>" sequencias.fasta | cut -d'|' -f3 | xargs -P 4 -I {} echo "Gene: {}"


# Xargs com arquivo
grep ">" sequencias.fasta | cut -d'|' -f2 | xargs -n 1 echo "Espécie:"


# Xargs com comando específico
ls *.fasta | xargs -I {} grep -c ">" {}


# Xargs com echo para debug
echo "arquivo1 arquivo2" | xargs -t echo  # -t mostra comando executado

11.3 Diferença entre Pipe e Xargs


# PIPE: comando recebe stdin
grep ">" sequencias.fasta | wc -l    # ✅ wc aceita stdin


# XARGS: comando recebe argumentos
grep ">" sequencias.fasta | xargs echo   # echo não aceita stdin, mas aceita args

11.4 Exercício

  1. Use xargs para criar diretórios para cada espécie no arquivo
  2. Use xargs com grep para contar sequências em todos os arquivos .fasta
Solução 

# 1. Criar diretórios por espécie
grep "^>" sequencias.fasta | cut -d'|' -f2 | sort -u | xargs mkdir -p


# 2. Contar sequências em múltiplos arquivos
ls *.fasta | xargs -I {} sh -c 'echo -n "{}: " && grep -c ">" {}'

12 Parte 8 – Compactação e Arquivos TAR

12.1 Tipos de Compactação


# Compressão individual
gzip sequencias.fasta          # cria .gz
gunzip sequencias.fasta.gz     # descomprime
bzip2 sequencias.fasta         # cria .bz2 (melhor compressão)
bunzip2 sequencias.fasta.bz2
xz sequencias.fasta            # cria .xz (melhor ainda)
unxz sequencias.fasta.xz


# Comparar tamanhos
ls -lh sequencias.fasta*

12.2 TAR (Tape Archive)


# Criar arquivo tar (sem compressão)
tar cvf arquivos.tar arquivo1 arquivo2 pasta/


# Compressão com tar (recomendado)
tar czvf arquivos.tar.gz arquivo1 arquivo2 pasta/   # gzip
tar cjvf arquivos.tar.bz2 arquivo1 arquivo2 pasta/  # bzip2
tar cJvf arquivos.tar.xz arquivo1 arquivo2 pasta/   # xz


# Descompactar
tar xzvf arquivos.tar.gz        # gzip
tar xjvf arquivos.tar.bz2       # bzip2
tar xJvf arquivos.tar.xz        # xz


# Ver conteúdo sem extrair
tar tvf arquivos.tar.gz


# Extrair arquivo específico
tar xzvf arquivos.tar.gz sequencias.fasta


# Extrair para diretório específico
tar xzvf arquivos.tar.gz -C /destino/

12.3 Comparação de Tamanhos

Formato Comando Tamanho
Original - 1.0 MB
gzip tar czvf 350 KB
bzip2 tar cjvf 280 KB
xz tar cJvf 210 KB

12.4 Exercício

  1. Compacte todos os arquivos .fasta em um arquivo sequencias.tar.gz
  2. Crie uma cópia de segurança de toda a pasta pratica1
  3. Compare os tamanhos dos arquivos compactados com diferentes algoritmos
Solução: 

# 1. Compactar todos .fasta
tar czvf sequencias.tar.gz *.fasta


# 2. Backup completo
tar czvf pratica1_backup_$(date +%Y%m%d).tar.gz pratica1/


# 3. Comparar algoritmos
tar czvf arquivo.tar.gz sequencias.fasta
tar cjvf arquivo.tar.bz2 sequencias.fasta
tar cJvf arquivo.tar.xz sequencias.fasta
ls -lh arquivo.tar.*
