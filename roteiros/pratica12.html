Aula Prática 12 – CellDesigner e COPASI

Autor

Nicholas Barroso

Data de Publicação

30 de agosto de 2026

1 🧬 Configuração e primeiro modelo

1.1 Objetivo

Aprender o fluxo CellDesigner → COPASI

1.2 Passos

  1. Instalar:
    • CellDesigner
    • COPASI
  2. Abrir CellDesigner
  3. Criar novo modelo:
    • File → New Model
    • Compartimento: cell
  4. Salvar como:
    • repressilator.cel

2 🧬 Construção do repressilador

2.1 Objetivo

Montar circuito genético visual

2.2 Passos

2.2.1 Criar espécies

Adicionar:

  • LacI
  • TetR
  • CI

2.2.2 Criar genes (transcriptional regulation)

No CellDesigner:

  • Add Gene
  • Nome:
    • pLac → LacI
    • pTet → TetR
    • pCI → CI

2.2.3 Criar interações

Adicionar:

  • LacI ┤ pLac
  • TetR ┤ pTet
  • CI ┤ pCI

Tipo:

  • inhibition (T-bar)

2.2.4 Produção

Adicionar setas:

  • pLac → LacI
  • pTet → TetR
  • pCI → CI

2.2.5 5. Exportar SBML

File → Export → SBML

Salvar como:

repressilator.xml

3 ⚙️ Prática 3 — Simulação no COPASI

3.1 Objetivo

Executar dinâmica oscilatória

3.2 Passos

3.2.1 1. Abrir COPASI

File → Open Model → repressilator.xml

3.2.2 2. Criar simulação

  • Time Course
  • Deterministic (ODE)
  • Duration: 5000
  • Steps: 10000

3.2.3 3. Rodar simulação

Clique:

  • Run

3.2.4 4. Plotar resultados

Selecionar:

  • LacI
  • TetR
  • CI

👉 Deve aparecer oscilação

4 🧪 Prática 4 — Ajuste de parâmetros

Alterar:

Parâmetro Efeito
alpha força de expressão
K sensibilidade
n cooperatividade
delta estabilidade

5 🧪 Prática 5 — Extensão do modelo

Adicionar:

  • ruído (stochastic simulation)
  • eventos (COPASI Events)
  • sensibilidade paramétrica
